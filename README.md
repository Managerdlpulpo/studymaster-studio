# StudyMaster Studio

App web para que los alumnos suban sus apuntes (texto, PDF, fotos o Word) y estudien con esquemas, tarjetas con repaso espaciado, preguntas abiertas, juegos y examen tipo test. Incluye la pestaña «Mi Progreso» y una vista de profesor de acceso restringido para recoger los informes de la clase (ver la sección 8 de `REVISION.md`).

Todo funciona en el navegador del alumno: sin servidor, sin cuentas y sin IA. Los apuntes no salen del dispositivo.

- `index.html`: la app.
- `REVISION.md`: informe de la revisión y mejoras.
- `tools/`: pruebas automáticas.
- `original/`: versión original antes de la revisión.
